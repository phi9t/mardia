# Qwen3-VL (Educational)

This directory provides a code-first educational reconstruction of the Qwen3-VL architecture themes:

1. Interleaved-MRoPE position handling.
2. DeepStack-style multi-level visual feature fusion.
3. Text-timestamp alignment for video grounding.
4. Multimodal SFT input formatting with image/video placeholders.

## Quick start

```bash
python -m qwen3_vl.validation.run_educational_smoke
python -m qwen3_vl.validation.compare_structure
```
